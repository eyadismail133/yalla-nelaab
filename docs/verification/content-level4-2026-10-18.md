## Changes and review

- Authority-only wrappers retain compact numeric exposure/response history in canonical snapshots. Guest catalogs use the plain registry, preserving lazy loading. Reducer action validation, scores, phase timing, views, private projections and result logic remain unchanged. Legacy in-progress snapshots without clocks are skipped instead of inventing per-question timings.
- Exports contain aggregate counts, mode and server recording timestamp, without actor IDs, names, answers or tokens. Stable per-question room/round keys deduplicate retries, rematches and host transfer. The runtime suppresses repeated result-publication transaction batches; failures can retry on later publication. These remain advisory browser-host aggregates, not trusted anti-cheat evidence.
- Optional rule fields preserve older clients/samples. Unauthenticated reads, guest/stale-host writes, overwrites and unexpected identifying fields remain restricted as before. New timestamps are server-resolved and validated.
- The [operator workflow](../CONTENT-REVIEW-WORKFLOW.md) uses existing authenticated Firebase CLI access. Reports validate samples, reject unknown items/aliased keys, group by mode, require 50 exposures and 20 answers for a difficulty suggestion, and identify source decisions. The default reporting window is 90 days; undated legacy samples are explicit. Exports are capped at 10 MiB. Database retention remains a reviewed manual operation; no production records were pruned.
- Source review corrected `fb-bool-75` and `fb-mcq-158`, added an explanation to the verified `fb-mcq-153`, and retained five verified answers. IDs, difficulty, supported shapes and all 8,901 playable items are preserved. [Source record](../CONTENT-REVIEW.md), [decision ledger](../../content/review-decisions.json): 91 dated claims triaged, five verified, two corrected, **84 still needing sources**. This is not a comprehensive bank audit.

Direct production/test diff review: **APPROVED**, subject to the recorded verification gates and publication checks. Reviewed accepted-action validation, exposure timing, timeout/cancellation semantics, sparse legacy snapshots, JSON restoration, immutable sample identity, privacy boundaries, export validation, rule compatibility, lazy loading, bounded metadata and source/seed diffs. No blocking findings remain. The new tests exercise real reducers/engine/runtime and rules, not mocked internal calls.
